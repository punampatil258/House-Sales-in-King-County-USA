# House Sales in King County, USA

## Project Overview

A data science project focused on analyzing house sales data and predicting house prices using machine learning.

## Objectives

* Perform data cleaning and exploratory data analysis.
* Analyze factors affecting house prices.
* Build regression models for price prediction.
* Evaluate model performance using R².

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Models

* Linear Regression
* Polynomial Regression
* Ridge Regression

## Files

* `House_Sales_in_King_Count_USA.ipynb` — Complete project notebook
* `housing.csv` — Dataset
* `requirements.txt` — Required Python libraries
